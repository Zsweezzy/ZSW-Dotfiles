================================================================================
                           CREATING A PLUGIN
================================================================================

  1. COPY TEMPLATE
     $ cp -r plugins/template/ plugins/my-new-widget

  2. EDIT MANIFEST
     plugins/my-new-widget/manifest.json
     ┌───────────────────────────────────┐
     │ {                                 │
     │   "name": "my-new-widget",        │
     │   "version": "1.0.0",             │
     │   "type": "bar-pill",             │
     │   "position": "right",            │
     │   "description": "..."            │
     │ }                                 │
     └───────────────────────────────────┘

  3. IMPLEMENT WIDGET
     plugins/my-new-widget/Widget.qml
     ┌───────────────────────────────────┐
     │ Module {                          │
     │   text: "NEW"                     │
     │   fg: Tokyo.fg                    │
     │   hoverStyle: true                │
     │                                   │
     │   signal clicked(int button)      │
     │   onClicked: { ... }              │
     │ }                                 │
     └───────────────────────────────────┘

  4. USE IN SHELL
     Component { id: widget; source: "plugins/my-new-widget/Widget.qml" }

================================================================================
                           DESIGN TOKENS (Tokyo.qml)
================================================================================

  Token          │ Use
  ───────────────┼────────────────────────────────
  Tokyo.fg       │ Primary text color
  Tokyo.bg       │ Surface fill
  Tokyo.pillBg   │ Bar pill background
  Tokyo.pillHeight│ Bar pill height (34)
  Tokyo.pillRadius│ Bar pill radius (10)
  Tokyo.fontSize │ Base font size (13)
  Tokyo.fontFamily│ Font family
  Tokyo.pillGap  │ Gap between pills

  ⚠️  NEVER use literal colors like "#1e2030"
